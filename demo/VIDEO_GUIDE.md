# StackDesk Demonstration

Run `make demo` from the repository root to execute the same C++ workflow shown in the video. Each phase starts a new process against the same temporary database. The program uses a fixed calendar and example contacts for a repeatable run.

| Approximate time | What to show | What it demonstrates |
| --- | --- | --- |
| 0:00–0:10 | Register two books and three readers | Stored titles, copy counts and reader tiers |
| 0:10–0:23 | Open the numbered menu and list the books | Shared database and the librarian's menu workflow |
| 0:23–0:40 | Borrow as a student and as faculty, then renew | Two virtual policy implementations selected at run time |
| 0:40–0:57 | Return the book, inspect the queue and advance to November 24 | Three eligible pickup days and automatic FIFO handoff |
| 0:57–1:12 | Start a new process, collect the saved hold and view stock | File persistence and a completed checkout after restart |
| 1:12–1:26 | Advance the date and export the four-day overdue loan | Sorted report, written CSV and confirmation |
